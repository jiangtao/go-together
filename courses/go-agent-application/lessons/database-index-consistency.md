## 原理与机制

数据库事务通常不能自动覆盖外部索引。系统需要用明确状态、可重复工作或补偿流程表达部分成功。页面显示“完成”的时点应与实际可查询能力一致，而不是与最早一次写入一致。

## 动手步骤

1. 追踪文档元数据、片段和索引的写入顺序，标出各自事务边界。
2. 定位处理中、失败、完成等实际状态的更新者，不自创状态名。
3. 在本地测试替换索引适配器，制造元数据已写但索引失败的情形。
4. 观察重试、重新解析或清理如何恢复，检查旧片段和新片段的身份。
5. 写出一个可验证不变量，例如完成状态不能对应缺失的有效索引；按项目真实约定调整。
