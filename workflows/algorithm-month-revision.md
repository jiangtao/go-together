# 算法复习 Course：37 天框架修订规格

## 问题

现有 `algorithm` 已覆盖主要模型，但只有 20 天，题组只分 Hot 100 与进阶，缺少从简单恢复到经典模板再到深入迁移的显式坡度；同时没有将 AI Agent 工作流中真正依赖的搜索、检索、调度与在线决策模型组成独立复习段。经典算法主线应完整独立为 30 天，Agent 映射另追加一周。

## 参考边界

- 只采用此前已确认的 Labuladong 算法路线高层主题：数组/链表/前缀与差分、栈队列哈希、双指针滑窗二分随机、递归树、BFS/DFS/回溯/分治/动态规划、BST/堆/Trie/图。
- 不访问、抓取、复述或保存 Labuladong 页面正文；课程内容继续以维护者笔记的主题和本仓库原创讲解为主。
- 题目仍仅保留 LeetCode CN 的最小题目元数据与链接，不复制题面、样例、提交代码或平台题解。

## 阶梯题组

每个 Lesson 的外部 Problem Reference 采用固定顺序：

1. **简单恢复**：一题低摩擦基础题，确认数据结构、边界或模板；
2. **经典模板（Hot 100 优先）**：一至三题常见模型题，形成可迁移实现；
3. **深入迁移**：一题更强约束、组合状态、证明要求或系统化变体。

每层都保留建议时限和单一复盘问题。不能把难题提前到恢复题之前，也不以题目难度代替模型分类。

## AI Agent 算法段

AI 相关内容只教授算法映射，不把特定模型、框架或供应商 API 当作必修前提：

- 规划：BFS、Dijkstra、A*、优先队列与状态启发；
- 检索：Top K、堆、倒排过滤、向量近邻的工程取舍；
- 上下文：背包、区间调度、缓存与预算分配；
- 工具编排：有向无环图、拓扑排序、关键路径和失败传播；
- 多 Agent：优先队列、队列、限流、幂等重试与资源公平；
- 在线选择：随机化、探索/利用和可观测评估边界；
- 综合：把上述模型组合成可解释的 Agent 任务执行流水线。
