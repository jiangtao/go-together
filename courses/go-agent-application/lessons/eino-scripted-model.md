## Node.js 对照

将 TypeScript 中的异步模型与工具调用映射到 Go 小接口、显式 error 和 context，避免把框架 SDK 类型扩散到业务层。

## 原理与机制

模型替身不是只返回字符串。它需要表达最终回答、工具调用、调用失败和取消，并观察收到的消息。Eino 版本间接口可能不同，应从当前版本接口和示例实现需要的方法，不拼接其他版本的代码。

## 动手步骤

1. 在固定 Eino 版本中找到 ChatModelAgent 所需模型接口及邻近示例。
2. 复用基础课 Day 31 的脚本场景与预期，适配当前框架模型接口；没有既有产物时再实现最小替身。脚本耗尽时返回明确错误，不再手写另一套 Agent 循环。
3. 运行直接回答场景，断言只调用一次模型且无工具调用。
4. 运行一次工具调用后回答的脚本，验证工具结果进入下一轮消息并保留关联 ID。
5. 增加模型报错和等待取消场景，证明循环能结束。

## 观察与产出

测试不访问外部模型；断言调用次数、输入消息和终态，而不是只断言没有 panic。
