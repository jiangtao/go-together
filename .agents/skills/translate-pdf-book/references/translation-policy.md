# PDF 书籍翻译规范 / PDF Book Translation Policy

## 1. 完整性 / Completeness

- 逐页翻译，不摘要、不合并章节、不跳过重复但有意义的内容。
- 保留标题层级、目录顺序、列表编号、图注、表注、脚注、引文归属与版本说明。
- 空白页保留页映射；纯视觉页说明其内容，或在双语版中依赖原页图像，并翻译可见图注。
- 跨页句子按原页断点续写，避免遗漏或重复。

## 2. 术语 / Terminology

- 首次出现默认使用“标准译名（English Term）”；后续按语境使用中文或保留英文缩写。
- LLM、API、MCP、RAG、JSON、SDK 等行业通用缩写通常保留英文。
- 产品、公司、模型、协议、库和框架名称保留官方拼写，如 OpenAI、Claude、Mastra、OpenTelemetry。
- 维护统一术语表。出现多个合理译法时，选择领域内更常用、歧义更小的一种，并全文一致。
- 不为追求“纯中文”而强行翻译会损害检索性或技术准确性的名称。

## 3. 代码与结构化内容 / Code and Structured Content

- 代码、命令、URL、路径、变量名、函数名、类型名、Schema 键和配置键保持原样。
- 仅翻译代码注释和解释性字符串，且确认不会改变可执行行为。
- 不凭空补全被截图截断的代码。双语版保留原页；阅读版明确提示读者参照原书代码页。
- 表格保持行列关系；JSON、YAML、XML 和 Markdown 的结构标记不得被中文标点破坏。

## 4. 风格 / Style

- 优先准确、专业、清晰，再追求自然流畅。
- 保留作者语气、幽默和论证强度，不擅自增强或弱化结论。
- 中文标点与中英文空格保持一致；数字、日期、币种和单位不得悄然改写。
- 发现源文疑似笔误时忠实翻译，并在必要时用简短译注说明，不静默改写事实。

## 5. 页级译文格式 / Page Mapping Format

```markdown
## Page 1

# 一级标题

正文。

### 小节标题

- 列表项

## Page 2

续文。
```

- 每个源页恰好对应一个 `## Page N`。
- 页号连续、唯一，并与 PDF 的物理页序一致。
- `#`、`##`、`###` 用于译文中的视觉层级；页边界只使用 `## Page N`。

## 6. QA 抽查 / Quality Assurance

至少抽查以下页面：

1. 封面与版权/版本页；
2. 目录页；
3. 前言或引言中的高密度正文页；
4. 每个 Part 的首章；
5. 代码、表格、图像或特殊字符最密集的页面；
6. 全书最后两页。

检查项：

- 源文专有名词、数字和否定词是否遗漏；
- 关键术语是否一致；
- 标题、列表、图注和正文是否错位；
- PDF 是否嵌入支持目标语言的字体；
- 纯目标语言版的文本提取结果是否只含译文和有意保留的英文术语；
- 全页低分辨率渲染数量是否等于 PDF 页数。
