## Node.js 对照

将 TypeScript 中的异步模型与工具调用映射到 Go 小接口、显式 error 和 context，避免把框架 SDK 类型扩散到业务层。

## 原理与机制

会话历史保存的是对话事实，检查点保存的是恢复执行所需状态。取消、中断等待和进程重启具有不同语义。恢复时必须知道恢复身份、已完成工具及重复执行边界，不能把数据库里有日志等同于可恢复。

## 动手步骤

1. 从上下文裁剪或中断恢复中选一个，阅读固定 Eino 版本的官方说明与最小示例。
2. 如果选上下文，构造超过预算的历史，记录保留、压缩或删除的规则及工具结果关联。
3. 如果选恢复，明确暂停位置、检查点存储、恢复标识和输入；按接口约定构造一次暂停/恢复。
4. 加入一个错误边界：缺失检查点、重复恢复或工具完成后中断，验证所选机制的行为。
5. 解释与 WeKnora 已观察的会话/任务状态有什么相同和不同，未验证能力明确标注。
