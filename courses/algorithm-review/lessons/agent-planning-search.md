# Agent 规划：状态搜索与启发式

## 算法映射

一个可解释的 Agent 规划器不是直接罗列工具名，而是定义状态、动作、目标、代价和停止条件。无权动作选择 BFS；不同动作代价选择 Dijkstra；A* 仅在启发式不高估剩余成本时保留最优性保证。工具失败、预算耗尽和循环状态都应进入状态模型，而非依靠提示词碰运气。

这是一种经典图搜索在 Agent 工作流中的映射，不依赖任何模型供应商或框架。真实系统还需要权限、超时和副作用约束，它们不属于搜索算法本身，但必须作为动作可行性条件表达。
