## Node.js 对照

## 原理与机制

JSON 缺失、null、空字符串和数值零可能有不同业务含义。Go 普通值字段的零值会掩盖“未提供”，指针或显式存在标记可以保留区别。校验与默认值的位置决定后续 service 看到的内容。

## 动手步骤

1. 选择一个与查询或检索有关的字段，从 UI、请求 DTO 追到业务使用点。
2. 列出字段缺失、合法值、边界值和错误类型四组输入，不随意探测生产接口。
3. 用现有测试工具为 Go handler 或 service 补充表驱动用例。
4. 观察错误从业务层到 HTTP 状态、响应字段及页面消息的映射。
5. 证明某个有效参数变化会影响对应业务调用，避免只断言响应非空。
