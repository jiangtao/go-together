# 在线选择：随机化与探索利用

## 算法映射

在线选择面对的是不完整反馈：系统必须在利用已知有效工具与探索可能更优工具之间分配预算。随机抽样、蓄水池抽样和加权选择提供了可分析的分布基础；多臂老虎机则是在持续反馈下调整选择概率的抽象。它们不保证单次选择最优，而是约束长期机会成本与探索覆盖。

Agent 中的在线选择必须与安全边界分离：不可逆或高风险工具不应只因随机策略而被调用。观测指标还要处理延迟反馈、样本偏差和成本，不可将单一成功率当作全部目标。
