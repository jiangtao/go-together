# 37 天算法速刷协议

前 30 天完成经典算法主线，第 31–37 天把其中的搜索、检索、调度与在线选择映射到 AI Agent 的可解释工作流。每节按同一循环执行：先用五分钟识别题型，再在十五分钟内写出状态和不变量，随后用 TypeScript 完成主实现；卡住时只回看模型，不直接搬运现成代码。最后用 Go 重写一道代表题，检查切片、映射和队列实现的差异。

题组固定分为三层：**简单恢复** 先确认容器、边界与模板；**经典模板（Hot 100 优先）** 建立可迁移的主模型；**深入迁移** 用更强约束或组合状态检验不变量。Day 1–30 的每个经典分类至少提供 10 道题，必须依次完成，不能把深入题提前为热身。题目只提供最小元数据和跳转链接，不复制任何题面、样例或平台内容。
