# Web 编辑器工程实战评测政策

English title: **Web Editor Engineering in Practice — Evaluation Policy**

## 权威范围

评测只使用显式指定的 `(courseId, lessonId)` 对应 Lesson、该 Lesson 在 Course Manifest 中声明的能力项，以及学习者提交的当前 Lesson 证据。Lesson 的以下栏目共同界定范围：学习目标、背景与问题、原理机制、核心术语、架构边界与取舍、实验、观察点、产出物、指标获取、常见失败、课后任务、能力项、评测提示和定向回炉。

不得使用其他 Day 的内容、模型记忆、隐藏答案或外部资料提高标准。外部链接用于学习，不自动成为额外考点。项目只是知识验证载体；提交大量代码不能替代对机制、边界和取舍的解释。

## 评测入口与事实源

- 评测必须交给 `$evaluate-course-lesson`，并显式使用 `courseId=editor-engineering` 与当前 `lessonId`。
- 私有 Evaluation 只能写入 `learning-records/editor-engineering/lessons/<lessonId>/evaluation.md`。
- Notes 和 Exercise 是学习证据，不得反向修改 Course、Evaluation Policy、Command Profile 或 Release Progress。
- 不得代写 Notes、答案、代码、指标结论或评测证据。

## 能力评分

每个 Manifest 能力项采用五级诊断分：

| 等级 | 判定 |
|---:|---|
| 4 | 准确解释机制、边界和取舍，并提供充分、可复现且能排除替代解释的证据 |
| 3 | 准确、完整地满足 Lesson 明确要求，关键产物与验证证据齐全 |
| 2 | 部分正确，但机制、边界、失败路径、指标方法或必要证据存在明显缺口 |
| 1 | 只有术语、结论、截图或未经验证的主张，不能解释因果关系 |
| 0 | 错误、缺失、与 Lesson 冲突，或证据不可审计 |

参考分数按“已得等级之和 /（能力项数量 × 4）× 100”四舍五入。只有每个必修能力项都达到 3 级或以上，Lesson 才能通过；高分不得抵消任一单项不合格。

## 证据规则

证据必须与当前 Lesson 的 requiredEvidence 对应，并由 Notes 明确列出仓库内相对路径。评测关注：

1. 机制证据：事件轨迹、transaction/step 记录、状态图、版本矩阵或收敛序列。
2. 工程证据：实现、自动测试、故障注入、ADR、runbook 或 API contract。
3. 指标证据：目标环境、夹具、样本量、采样方法、p50/p95、失败率、更新体积或恢复时间。
4. 观察结论：必须把数据与判断连接起来，不能只提交截图或最终数字。

指标不能跨设备或跨夹具直接比较。性能优化必须同时提供优化前基线、优化后结果与正确性回归；协同测试必须证明最终结构相等或 state vector/update 差异已归零，不能只凭肉眼观察两个页面相似。

Day 0 不要求业务代码。其必修证据是架构观察、资料阅读记录、个人目标和对工程指标的判断；不得因没有代码降低或提高标准。

## 问答纪律

1. 每次只问一道题，优先采用当前 Lesson 的“检索问题”或“判断题”。
2. 覆盖 Manifest 中全部能力项后才能结束，不预设固定题量。
3. 回答含糊时只能围绕同一能力项受限改写，不得引入其他 Lesson 的知识。
4. 工程产物不能替代口头或书面机制解释；解释也不能替代 Lesson 明确要求的工程证据。
5. 学习者回答必须由学习者写入 Notes，评测器不得润色、补全或代写。

## 零答案泄露

评测期间严禁输出标准答案、参考实现、正确代码、关键 API 组合、伪代码、推导步骤、选项排除或能暗示正确方向的相邻知识。允许输出的反馈仅包括：未达标能力项、问题类型、最短证据定位、失败标准、当前尝试次数以及需要重读的当前 Lesson 小节。

课程正文中的示例用于教学，不得在评测时扩写成学习者答案。判断题只记录学习者判断与理由，不提供答案键。

## 定向回炉

未达标时记录：

- competencyId 与当前等级；
- 问题类型：概念混淆、机制缺失、边界不清、取舍无依据、证据不足、指标无效或实现不可靠；
- 用户回答或产物中的最短定位；
- 当前 Lesson“定向回炉”表中的入口和重读小节；
- 当前尝试次数。

随后只要求重读指定小节、重做最小实验或补充指定证据，并重新评测同一能力项。每项最多三次；第三次仍低于 3 级时标记“重新学习”，停止当前 Lesson，不得提前进入后续内容。

## 自动命令边界

只有当前 Lesson 正文逐行明确列出的命令才可自动运行，并且还必须被 `evaluation/command-profile.json` 唯一匹配。允许的命令类别仅限本地、无网络、非生成式验证：TypeScript 类型检查、lint、单元/集成测试、浏览器测试、benchmark 与构建。

命令必须作为 argv 直接执行，禁止 shell 拼接、重定向、命令替换、环境变量赋值、网络地址、安装依赖、启动长期服务、生成或改写课程/学习记录。测试若需要外部网络、真实数据库、云服务、密钥、浏览器登录态或生产资源，不得自动运行，只检查学习者提供的脱敏证据。

格式化、依赖安装、数据库 migration、部署、回滚和写入操作均不由评测器执行。

## 安全与隐私

- Notes、日志、截图和 telemetry 证据不得包含文档正文、个人身份、访问令牌、cookie、DSN、连接串或真实用户数据。
- Awareness 样例只能使用虚构身份；协同房间名不得含敏感标识。
- 发现敏感信息、路径越界、symlink、越权或命令注入时立即停止评测。
- 安全停止不计为知识错误，清理风险后由学习者显式继续。

## 发布关系

本课程当前为 Draft。学习者 Evaluation 不会自动发布课程。发布必须由维护者明确请求，完成全部 authoring files、从私有 Evaluation 派生 Release Progress，并通过公开生成、确定性检查、公开审计和 prebuilt hosting 构建。Draft 源不得进入公开 Catalog。
