# Agent 上下文：预算、装箱与缓存

## 算法映射

上下文窗口是一种受限容量：每份证据有长度成本、任务相关价值和失效时间。背包模型帮助选择有限预算中的高价值组合；区间调度帮助安排不能并行的长任务；缓存淘汰帮助避免重复获取。真实上下文选择常需要近似算法，因为精确背包在候选多时成本过高。

价值函数必须可解释，例如覆盖的约束、来源可信度和去重收益；不能只以模型偏好替代明确目标。缓存命中也不是正确性证明，失效键和来源版本同样重要。
