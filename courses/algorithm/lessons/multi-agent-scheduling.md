# 多 Agent 调度：队列、优先级与限流

## 算法映射

多 Agent 的重点不是“多开几个并发”，而是定义资源与公平性：任务有优先级、截止时间和重试预算，执行器有容量，外部工具有冷却或速率限制。普通队列保证先到先服务，优先队列保证重要任务优先，冷却窗口避免短时间重复撞击同一资源。

重试必须带幂等键和指数退避；否则优先队列会放大失败任务。调度算法只解决何时派发，不替代权限校验、成本上限和人工升级条件。
