# 算法复习课程政策

本课程的学习记录以题型判断、复杂度、边界覆盖与代码可读性为依据。每次练习先记录模型选择和不变量，再编写 TypeScript 主实现，并补充 JavaScript 运行时差异或 Go 对照。

课程正文不保存题目全文、样例、平台提交结果或完整现成实现；题目链接仅用于学习者自行进入原平台。

## GitHub Issue 作答流程

本 Course 可以将学习者回答放入本机配置指定的私有 GitHub 答题仓库。每个答题 Issue 只属于一个稳定学习身份 `(courseId, lessonId)`；学习者自行填写回答和最小证据，自动化不得代写、润色、覆盖或公开回答。

答题 Issue 的 `answer:open`、`review:pending`、`review:passed`、`review:revision-needed` 和 `review:blocked` 标签只表达远程作答与审核流程。它们不是评分、Progress 或通过结论；本机 Evaluation Record 仍是唯一评测事实源，并继续遵守本 Course 的零答案泄露、证据范围和安全边界。

## GitHub Answer-Issue Workflow

This Course may keep learner-authored answers in a private GitHub answer repository selected by local configuration. Each Answer Issue belongs to exactly one stable identity, `(courseId, lessonId)`; the learner writes the answer and minimal evidence, while automation must never author, polish, overwrite, or publish that content.

The `answer:open`, `review:pending`, `review:passed`, `review:revision-needed`, and `review:blocked` labels describe only the remote answer and review workflow. They are not a score, Progress, or a passing result. The local Evaluation Record remains the sole source of evaluation fact and retains this Course's no-answer-leakage, evidence-scope, and safety boundaries.
