# 答题 Issue 不拥有评测事实

学习者回答需要 GitHub Issue 的异步协作能力，但当前课程仓库是公开的，且 Evaluation Record 已是稳定学习身份的本地评测事实。我们将 Answer Issue 固定为配置指定私有仓库中的回答载体，使用审核状态标签协调流程；Evaluation Record、Progress 和 Release Progress 继续由本机 Evaluation Core 维护，答题 Issue 不能反向写入它们。

## English

Learner answers need the asynchronous collaboration capabilities of GitHub Issues, while the current course repository is public and the Evaluation Record is already the local evaluation fact for a stable learning identity. An Answer Issue is therefore an answer carrier in a configured private repository, coordinated only by review-status labels. Evaluation Record, Progress, and Release Progress remain owned by the local Evaluation Core; an Answer Issue must never write back into them.
